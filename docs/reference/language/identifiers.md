# Identifiers

An actor id and a panel name are both an **identifier**, and follow one grammar. This page is
normative: the JSON Schemas, `scenet check`, `scenet build` and the comic-script frontend all
read it from one definition, so they accept and refuse exactly the same names.

| Where it is written | What it names |
|---|---|
| A key of `cast:`, in a panel, a scene, a script's front matter or an `@cast:` | An actor |
| `by:` on a `say`, the subject and object of a staging sentence | An actor, by that key; or, for a line from off panel, somebody nobody draws |
| A key of `panels:` in a scene; a script's `PANEL` heading, with its `PAGE` when numbers repeat | A panel |
| `over:`, `@over:`, and each panel a page's tiers and columns lay out | A panel, by that name |

## The grammar

An identifier is:

- **1 to 64 characters**, counted as Unicode code points;
- made of **letters, decimal digits, `_` and `-`**, and the combining marks that accent a
  letter;
- **starting with a letter or a digit**;
- never one of the [reserved words](#reserved-words), in any case.

| Accepted | Refused, and why |
|---|---|
| `alice`, `ALICE`, `old_man`, `mary-jane` | `old man`: a space would split a staging sentence |
| `Zoé`, `健`, `हिन्दी`, `Ἀθηνᾶ` | `a/b`, `x.debug`, `../../evil`: [reserved characters](#reserved-characters) |
| `7`, `2-1`, `4B`, the page and panel a script names | `-a`, `_a`: an identifier starts with a letter or a digit |
| `left_ofs`, `caps`: a reserved word with more to it | `left_of`, `Caption`, `SFX`: [reserved words](#reserved-words) |
| | `""`, and anything longer than 64 characters |
| | `o'neil`, `a\b`, an emoji, a tab: not a letter, a digit, a mark, `_` or `-` |

A refusal is one [`invalid-identifier`](../diagnostics.md#invalid-identifier) finding at the
name, saying which part of the grammar it breaks and stating the grammar. A panel is refused
by `scenet check` exactly as by `scenet build`, before any file is named after it.

```yaml
cast:
  Zoé: {reference: alice, at: left_third}
  健: {reference: bob, at: right_third, facing: left}
staging:
  - Zoé left_of 健
script:
  - say: {by: Zoé, text: "Ready?"}
  - say: {by: 健, text: "Always."}
```

### Letters, digits and marks

A **letter** is a character of Unicode's general categories Lu, Ll, Lt, Lm and Lo; a **digit**
one of Nd, the decimal digits of every script; a **mark** one of Mn and Mc, which spell many a
letter — `é` written as `e` and an accent, every vowel sign of Devanagari. A mark may follow, and
never start, an identifier. Numerals that are not decimal digits, `Ⅻ` or `²`, are refused, and so
are emoji, punctuation, spaces and the invisible joiners.

The categories are read from **Unicode 16.0.0**, and the characters they hold are spelled out,
one range at a time, in the schema's pattern. Python's regular expressions have no class for "a
letter", and an editor's follows whichever Unicode its engine ships, so a class would let two
readers of the same schema disagree about a letter one knows and the other does not. The table
is generated by `scripts/build_identifier_tables.py` into `scenet/identifier_tables.py`, and moves
to a newer Unicode only as a change of its own.

Names are compared as written, character by character: they are not normalised. `Zoé` with its
accent as one character and `Zoé` written as `e` and an accent are two identifiers that look the
same; write each name the same way everywhere, as an editor usually does.

## Reserved characters

Five characters are never part of an identifier, so a name written today can never mean
something else when the language gives them a meaning:

| Character | Kept for |
|---|---|
| `/` | A [qualified reference](#qualified-references): `chapter/panel`. It also separates folders, and a panel's name is part of the name of every file it is written to |
| `#` | A reference to a panel in another document: `file#panel` |
| `.` | A file name's extension: a panel `x.debug` would have written over panel `x`'s debug overlay, and `..` climbs out of the folder |
| `:` | YAML's and a comic script's separator between a key and its value, and a drive on Windows |
| `@` | A comic script's directives, `@cast:` and `@over:` |

## Reserved words

These words are never an identifier, compared without case — as Python's `str.casefold`
compares them, so `Left_Of`, `LEFT_OF` and a `sfx` spelled with the long `ſ` are all refused:

| Words | Why |
|---|---|
| `left_of`, `right_of`, `in_front_of`, `behind`, `looking_at`, `ground_shared_with` | The predicates of a staging sentence, which reads its middle word as one: an actor called `behind` would make `behind behind bob` a sentence nobody can read |
| `cap`, `caption`, `sfx` | A comic script reads a line that starts with one as a caption or a sound effect, so a cast member called `CAP` could never speak |
| `récitatif`, `recitatif`, `narratif`, `cartouche`, `onomatopée`, `onomatopee` | The same labels in a French script |

They are reserved in YAML as in a script, so a document can be rewritten as the other without
renaming anybody.

## An identifier written as a value

A key is text as written, so `cast: {1984: …}` keys the actor `1984`. A **value** that names an
actor where nobody declares it — `by:` on a line from off panel — is text too, and written in
quotes when it looks like a number or a yes-or-no: `by: '1984'`. Unquoted, `1984` is a number, and
a JSON Schema sees `1984` and `1984.0` as one; only the text as written can be an id, so a number
there is an `invalid-identifier` finding that says to quote it.

```yaml
cast:
  "1984": {reference: alice}
script:
  - say: {by: "1984", text: "Big Brother is watching."}
```

## Qualified references

A panel is named, today, by its name alone, within its own document. A book of several
documents will need to name a panel of another one, and the reference forms it will use are
specified now, so that no identifier written before they arrive can be mistaken for one:

| Form | Status | Names |
|---|---|---|
| `panel` | In the language | The panel `panel` of this document |
| `chapter/panel` | Specified; not yet accepted | The panel `panel` of the chapter `chapter` of a book, each part an identifier. The form a book's panels are keyed by, and its Book Core's panel ids |
| `file#panel` | Reserved | A panel of another document, named by that document |

Until a book is part of the language, a name with a `/` or a `#` in it is refused like any other
reserved character. How a book names its chapters and finds its files is the album model, which
is still to be decided.

## In the JSON Schema

The panel and scene schemas define the pattern once, as `$defs/Identifier`, and refer to it from
the cast's keys (`propertyNames`), from `by:`, and from the keys of `panels:`. It is written in the
regular expressions Python's and ECMAScript's agree on — ECMAScript's with the `u` flag, as JSON
Schema 2020-12 reads them — and ends on `(?![\s\S])` rather than `$`, which in Python also matches
before a final line break. A schema validator and `scenet check` refuse the same names; a test
runs every row of a table of names through the schema, the validator and the comic-script
frontend, and holds the three to one verdict.
